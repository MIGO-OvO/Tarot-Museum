# 塔罗牌文档补全设计说明

- 日期：2026-06-15
- 主题：Tarot Museum 项目 78 张塔罗牌正文文档补全

## 目标

在不改动现有 `docs/major/01-the-magician.md` 与 `docs/major/02-the-high-priestess.md` 的前提下，为项目补齐其余缺失的 76 张塔罗牌正文解读文档。

本轮工作只补正文解读，不生成生图提示词文档。所有新增文档需参考权威塔罗资料进行整理，但正文中不展示外部来源，而是统一消化为当前项目适配的中文解读风格。

## 现状

当前项目中已存在的塔罗正文文档只有两张：

- `docs/major/01-the-magician.md`
- `docs/major/02-the-high-priestess.md`

同时还存在对应的 prompt 文档，但本轮不处理。

现有两篇正文在结构与文风上存在差异：

- 《魔术师》偏口语化、铺陈式、栏目完整。
- 《女祭司》更偏整理式结构，栏目更规整。

因此，后续新增文档将采用“保留栏目习惯、统一模板、允许牌义驱动语气细节变化”的策略。

## 范围

### 包含

- 大阿卡纳缺失牌面：`00 愚者`、`03 皇后` 至 `21 世界`
- 小阿卡纳全部 56 张：权杖、圣杯、宝剑、星币四组的王牌至国王
- 为每张牌新增一篇独立正文 `.md` 文件

### 不包含

- 不重写或改动现有《魔术师》《女祭司》正文
- 不生成任何 `-prompts.md` 文档
- 不处理网页代码、路由、导航或页面渲染逻辑
- 不在正文中加入显式参考来源列表

## 目录结构

采用分组清晰的目录方案：

- 大阿卡纳：`docs/major`
- 小阿卡纳：
  - `docs/minor/wands`
  - `docs/minor/cups`
  - `docs/minor/swords`
  - `docs/minor/pentacles`

## 编号与命名规则

采用完整 78 张体系，愚者放在最前面，编号为 `00`。

### 大阿卡纳

- `docs/major/00-the-fool.md`
- `docs/major/03-the-empress.md`
- ...
- `docs/major/21-the-world.md`

其中 `01-the-magician.md` 与 `02-the-high-priestess.md` 保持原样。

### 小阿卡纳

小阿卡纳承接大阿卡纳之后继续编号，范围为 `22–77`。

示例：

- `docs/minor/wands/22-ace-of-wands.md`
- `docs/minor/wands/35-king-of-wands.md`
- `docs/minor/cups/36-ace-of-cups.md`
- `docs/minor/swords/50-ace-of-swords.md`
- `docs/minor/pentacles/64-ace-of-pentacles.md`
- `docs/minor/pentacles/76-queen-of-pentacles.md`
- `docs/minor/pentacles/77-king-of-pentacles.md`

## 统一正文模板

每张新增文档采用统一的讲解型中文结构，保留现有项目栏目习惯：

1. `# 牌名`
2. 简介导语：1–2 段，概括牌的核心气质与主题
3. 主图引用：引用未来图片路径，路径规则与牌名 slug 对齐
4. 牌面解读：整体画面、人物/场景、象征主题、精神内核
5. `## 基础要素`
   - 数字编号
   - 元素
   - 星座 / 行星（适用时）
   - 希伯来字母 / 数秘 / 花色属性（按牌类适配）
6. `## 牌面要素`
   - 使用表格列出关键视觉符号与对应含义
7. `## 塔罗灵数`
   - 大阿卡纳与数字牌强调数字主题
   - 宫廷牌则写其人格结构与角色属性，不强行套数字段落
8. `## 正位牌意`
   - 关键词
   - 爱情 / 婚姻
   - 事业 / 学业
   - 人际 / 财富
   - 健康 / 生活
   - 其它牌意
9. `## 逆位牌意`
   - 关键词
   - 爱情 / 婚姻
   - 事业 / 学业
   - 人际 / 财富
   - 健康 / 生活
   - 其它牌意

## 写作规范

### 资料依据

- 使用 Tavily 检索权威塔罗资料作为事实基础
- 优先参考主流 Rider–Waite–Smith / Golden Dawn 体系
- 若资料之间存在细节差异，统一采用一套前后一致的主流解释口径

### 风格要求

- 保持中文讲解型、可阅读性强的写法
- 不写学术综述，不展示外部来源
- 不照搬网络词条，要做信息整合与语言整理
- 保持栏目一致，但允许根据牌的象征气质微调语气
- 既保留神秘学语境，也要兼顾现代读者对感情、事业、财富、健康等场景的阅读习惯

### 一致性要求

- 同一张牌内部的基础要素、牌面象征、正逆位解释必须彼此一致
- 同一套牌之间的元素逻辑要统一，例如：
  - 权杖偏火与行动
  - 圣杯偏水与情感
  - 宝剑偏风与思想
  - 星币偏土与现实、资源、身体、物质
- 宫廷牌需统一角色梯度：侍从、骑士、王后、国王

## 实施策略

为保证质量与一致性，实施时按以下顺序推进：

1. 先建立目录结构与命名基准
2. 先补大阿卡纳缺失牌面
3. 再按花色顺序补小阿卡纳：权杖 → 圣杯 → 宝剑 → 星币
4. 每组内部保持统一模板，但逐张根据牌义细调导语、正逆位语气与场景描述
5. 完成后抽检编号连续性、标题一致性、图片路径一致性、栏目完整性

## 风险与处理

### 风险 1：现有两篇风格不一致

处理：不回头重写已有文档，而是以后续新增文档建立统一基线。

### 风险 2：不同塔罗体系对应信息不一致

处理：统一以 Rider–Waite–Smith / Golden Dawn 为主，不在文中展开体系争议。

### 风险 3：一次性补 76 张，工作量大

处理：严格使用统一模板，分批生成并持续抽检，优先保证结构一致与可用性。

## 完成标准

当以下条件全部满足时，本任务视为完成：

- 缺失的 76 张塔罗正文文档已全部创建
- 所有新增文档都位于约定目录下
- 文件命名与编号连续、正确
- 每篇都符合统一模板
- 内容已参考权威资料并消化为统一中文风格
- 已存在的两篇文档未被改动
